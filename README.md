# 🛍️ E-Commerce Image Mapping Project

## 📌 Project Overview

This project demonstrates the concept of **Image Mapping in HTML**.  
Users can click on different areas of a single image to navigate to various e-commerce websites.

It is a simple front-end project built using **HTML and CSS**.

---

## 🎯 Aim

To create an interactive webpage using HTML image mapping where multiple clickable regions redirect users to official brand websites.

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts (Poppins)
- Image Map (`<map>` and `<area>` tags)

---

## 🚀 Features

- Clean and modern UI design
- Gradient background
- Responsive layout
- Hover effects on brand cards
- Clickable image regions that open:
  - Flipkart
  - Nykaa
  - Myntra
  - Amazon
  - Meesho
- Opens links in new tab

---

## 🧠 Concept Used

### 📍 Image Mapping

Image mapping allows specific parts of an image to act as hyperlinks.

Example:

```html
<map name="ecomap">
   <area shape="rect" coords="0,0,300,200" 
   href="https://www.flipkart.com" target="_blank">
</map>
